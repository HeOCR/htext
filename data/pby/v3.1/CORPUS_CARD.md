# htext pby-v3.1

Public-domain Hebrew literature from Project Ben-Yehuda, cut into plain and pointed lines. This revision ships the Israel variants only.

The text files are filtered derivatives of [the original pby-v3 build](https://github.com/HeOCR/htext/blob/main/data/pby/v3/corpus_card.json).
HeOCR's corrected independent check found zero shared 6-grams across 16 evaluation pools for these exact files.
This check describes text overlap, not OCR performance.

| Text file | Lines | Bytes |
| --- | ---: | ---: |
| `pby_lines_il_plain_v3.txt` | 11,937,498 | 543,363,626 |
| `pby_lines_il_niqqud_v3.txt` | 1,672,711 | 119,281,529 |

Each text file has a matching line index. [SHA256SUMS](SHA256SUMS) pins both.
Download the tagged revision on [Hugging Face](https://huggingface.co/datasets/HeOCR/htext-pby/tree/pby-v3.1).
